The PureDogPWA home.

An installable Progressive Web App that stays minimal on desktop, tablet, or mobile. It just works.

And it’s really meant to stay clean and simple.

PureDogPWA is a mash up of three things

  1. Pure CSS responsive layout at PureCSS.io. It resizes and works across screen sizes.
  2. Doggone Minimal Website (DMW) styling inspired by github.com/crrdlx/doggone-minimal-website — readable type and a light page.
  3. PWA basics: a web app manifest plus a service worker so the app can be installed and cached for offline-first navigation.

How to use this template

Grab the code from GitHub. You can clone the repository or download a ZIP, then customize titles, colors, and copy.

  • Clone the repository (Code → Clone), or
  • Download the ZIP (Code → Download ZIP).

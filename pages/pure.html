Pure CSS in this project

Pure provides the grid and menu primitives. The look of headings, body type, and tables follows the Doggone Minimal Website pattern in css/dmw-pwa.css.

You can change layout colors in side-menu.css. The menu toggle uses a small script in ui.js that adds an active class for small screens.

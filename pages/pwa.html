Progressive Web App

What “installable” means here and how this repo satisfies it.

The PWA notes.

A Progressive Web App can be installed so it opens in its own window, with a safe offline cache for static assets.

  1. Small footprint compared with many store apps.
  2. Updates ship when you refresh or when a new service worker activates.
  3. No app store gatekeeper for distribution.

What this project includes

  • <link rel="manifest" href="…/manifest.json"> on every page.
  • manifest.json with name, icons (192 and 512), start_url, display, and scope.
  • sw.js precaching core HTML, CSS, JS, and icons, plus a fetch handler for offline fallback.

Use HTTPS (or localhost) when testing install prompts in Chromium-based browsers.

Try it

Open the site from a local or HTTPS server, wait for the service worker to finish installing, then use the browser’s install / add-to-home-screen option when it appears.
